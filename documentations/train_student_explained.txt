================================================================================
train_student.py - DETAILED EXPLANATION
Knowledge Distillation Training Script
================================================================================

PURPOSE:
This script trains a small, fast STUDENT model using knowledge transferred from
a pre-trained TEACHER model. Supports 10 different distillation methods including
the main PKT (Probabilistic Knowledge Transfer) algorithm from the paper.

CORE CONCEPT:
Instead of training the student from scratch with only hard labels (0/1), we use
the teacher's soft predictions and intermediate features to guide learning. This
results in a student model that is much smaller but nearly as accurate as the teacher.

================================================================================
IMPORTS AND UNIQUE COMPONENTS
================================================================================

Key Differences from train_teacher.py:

1. Distillation Methods:
   from crd.criterion import CRDLoss
   from distiller_zoo import DistillKL, HintLoss, Attention, Similarity, VIDLoss, SemCKDLoss, PKT

2. Projection Modules:
   from models.util import ConvReg, SelfA, SRRL, SimKD
   These align features between teacher and student when dimensions don't match

3. Special Data Loaders:
   from dataset.cifar100 import get_cifar100_dataloaders_sample
   For contrastive learning (CRD method)

4. Path Handling:
   split_symbol = '~' if os.name == 'nt' else ':'
   Windows uses '~', Unix uses ':' for model naming

================================================================================
FUNCTION: parse_option()
================================================================================

ADDITIONAL PARAMETERS (compared to train_teacher.py):

Student and Teacher:
--model_s (default: 'resnet8x4')
  - Student model architecture
  - Should be much smaller than teacher
  - Example: resnet8x4 vs resnet32x4 teacher

--path_t (required)
  - Path to pre-trained teacher checkpoint
  - Example: './save/teachers/models/resnet32x4_vanilla_cifar100_trial_0/resnet32x4_best.pth'

Distillation Method:
--distill (default: 'kd')
  - Which knowledge distillation method to use
  - Choices: 'kd', 'hint', 'attention', 'similarity', 'vid', 'crd', 'semckd', 'srrl', 'pkt', 'simkd'

Loss Weights:
-c, --cls (default: 1.0)
  - Weight for classification loss (student logits vs true labels)
  - Set to 0 for pure distillation without supervision

-d, --div (default: 1.0)
  - Weight for KL divergence loss (student logits vs teacher logits)
  - Classic knowledge distillation component

-b, --beta (default: 0.0)
  - Weight for method-specific distillation loss
  - For PKT: typically 1.0
  - For FitNet: 100-1000
  - For Attention: 1000

Temperature:
--kd_T (default: 4)
  - Temperature for softening probability distributions
  - Higher T = softer probabilities = more dark knowledge
  - T=1: standard probabilities
  - T=4: much softer (standard choice)

Method-Specific:
--hint_layer (default: 1)
  - Which layer to use for FitNet hints
  - Choices: 0, 1, 2, 3, 4 (corresponding to different network depths)

--factor (default: 2)
  - Channel reduction factor for SimKD
  - Controls projection bottleneck size

--soft (default: 1.0)
  - Attention scale for SemCKD

CRD-Specific:
--feat_dim (default: 128)
  - Embedding dimension for contrastive learning

--nce_k (default: 16384)
  - Number of negative samples for NCE loss

--nce_t (default: 0.07)
  - Temperature for contrastive softmax

--nce_m (default: 0.5)
  - Momentum for updating memory bank

Other:
--skip-validation
  - Skip teacher validation (faster startup)
  - Useful when you trust teacher checkpoint

--deterministic
  - Make results reproducible (seeds random generators)
  - Disables cudnn.benchmark for consistency

MODEL NAMING:
Generated name format:
  S~{student}_T~{teacher}_{dataset}_{method}_r~{cls}_a~{div}_b~{beta}_{trial}

Example:
  S~resnet8x4_T~resnet32x4_cifar100_pkt_r~1.0_a~1.0_b~1.0_0

This encodes all key information in the filename.

FUNCTION: get_teacher_name(model_path)
================================================================================

WHAT IT DOES:
Parses the teacher model name from its checkpoint path

INPUT: './save/teachers/models/resnet32x4_vanilla_cifar100_trial_0/resnet32x4_best.pth'
OUTPUT: 'resnet32x4'

WHY THIS MATTERS:
- Need to know teacher architecture to load correct model
- Handles both vanilla teachers and distilled teachers
- Special handling for Wide ResNets (wrn_XX_X format)

PARSING LOGIC:
1. Extract directory name: 'resnet32x4_vanilla_cifar100_trial_0'
2. Try pattern matching for distilled models: 'S~model_T~...'
3. Otherwise, split by '_' and take first segment
4. Special case: 'wrn_40_2' needs all three parts

================================================================================
FUNCTION: load_teacher(model_path, n_cls, gpu, opt)
================================================================================

WHAT IT DOES:
Loads pre-trained teacher model from checkpoint

STEP-BY-STEP:
1. Determine teacher architecture from path
2. Create model instance: model = model_dict[model_t](num_classes=n_cls)
3. Load checkpoint with proper device mapping
4. Load state_dict into model

DEVICE MAPPING:
map_location = {'cuda:0': 'cuda:%d' % gpu}
- Ensures checkpoint loads to correct GPU in multi-GPU setup
- Prevents CUDA errors when checkpoint was saved on different device

WEIGHTS_ONLY=FALSE:
torch.load(..., weights_only=False)
- Allows loading full checkpoint (not just weights)
- Includes epoch, accuracy, etc.

SECTION 2: LOAD TEACHER AND INITIALIZE STUDENT
---

Code:
  model_t = load_teacher(opt.path_t, n_cls, opt.gpu, opt)
  model_s = model_dict[opt.model_s](num_classes=n_cls)

TEACHER:
- Already trained, frozen weights (no updates)
- Provides guidance through features and logits
- Larger capacity (more parameters)

STUDENT:
- Initialized randomly
- Will be trained with distillation
- Smaller capacity (fewer parameters)

EXAMPLE:
Teacher: resnet32x4 with ~2.76M parameters
Student: resnet8x4 with ~0.015M parameters (184x smaller!)

Code:
  model_t.eval()

      data = torch.randn(2, 3, 32, 32)
  feat_t, _ = model_t(data, is_feat=True)
  feat_s, _ = model_s(data, is_feat=True)

WHY THIS TEST?

- Verifies models work with is_feat=True

OUTPUT SHAPES (example):
feat_t = [f0_t, f1_t, f2_t, f3_t, f4_t]

  f2_t: [2, 64, 16, 16]   # After layer2
  f3_t: [2, 128, 8, 8]    # After layer3
  f4_t: [2, 128]          # After avgpool (USED FOR PKT)

feat_s = [f0_s, f1_s, f2_s, f3_s, f4_s]
  Similar structure but potentially different dimensions

---
SECTION 4: MODULE LIST AND TRAINABLE LIST
---

Code:
  module_list = nn.ModuleList([])
  module_list.append(model_s)
  trainable_list = nn.ModuleList([])
  trainable_list.append(model_s)

TWO LISTS:
1. module_list: All modules needed for forward pass
   - Includes student, projections, teacher
   - All moved to GPU together

2. trainable_list: Only modules that will be trained
   - Does NOT include teacher (frozen)
   - Only these get gradient updates

LATER:
  module_list.append(model_t)  # Teacher added to module_list
  # But NOT to trainable_list!

WHY SEPARATE LISTS?
- Teacher must be in forward pass (module_list)
- But should not be trained (not in trainable_list)
- Optimizer only updates trainable_list.parameters()

---
SECTION 5: SETUP DISTILLATION METHOD
---

This is the heart of the script. Different methods require different components:

5A. KD (Knowledge Distillation) - Baseline
==========================================
Code:
  if opt.distill == 'kd':
      criterion_kd = DistillKL(opt.kd_T)

Simple KL divergence on logits. No additional modules needed.

Loss:
  KL_div(softmax(student_logits/T), softmax(teacher_logits/T))

5B. HINT (FitNet) - Intermediate Feature Matching
==========================================
Code:
  elif opt.distill == 'hint':
      criterion_kd = HintLoss()
      regress_s = ConvReg(feat_s[opt.hint_layer].shape,
                          feat_t[opt.hint_layer].shape)
      module_list.append(regress_s)
      trainable_list.append(regress_s)

ConvReg:
- Aligns student feature to match teacher feature dimension
- Uses 1x1 convolutions + adaptive pooling
- Example: [B, 64, 16, 16] → [B, 128, 16, 16]

Loss:
  MSE(regress_s(student_feat), teacher_feat)

WHY NEEDED?
Teacher and student features have different dimensions.
Can't compute MSE directly on mismatched shapes.

5C. ATTENTION TRANSFER - Spatial Attention Matching
==========================================
Code:
  elif opt.distill == 'attention':
      criterion_kd = Attention()

No additional modules needed.

Process:
1. Compute attention maps for each feature
   attention = mean over channels, then normalize
2. Match attention maps between teacher and student
   Loss = sum of MSE on attention maps

Intuition:
"Where the teacher pays attention, the student should too"

5D. SIMILARITY PRESERVATION - Gram Matrix Matching
==========================================
Code:
  elif opt.distill == 'similarity':
      criterion_kd = Similarity()

Process:
1. Compute Gram matrix: G = F × F^T
   G[i,j] = similarity between sample i and sample j
2. Match Gram matrices: MSE(G_student, G_teacher)

Intuition:
"If samples A and B are similar in teacher's space,
 they should be similar in student's space too"

5E. VID (Variational Information Distillation)
==========================================
Code:
  elif opt.distill == 'vid':
      s_n = [f.shape[1] for f in feat_s[1:-1]]
      t_n = [f.shape[1] for f in feat_t[1:-1]]
      criterion_kd = nn.ModuleList([VIDLoss(s, t, t) for s, t in zip(s_n, t_n)])
      trainable_list.append(criterion_kd)

VIDLoss:
- Learns a variational bound on mutual information
- Each layer pair gets its own VID module
- Parameters inside VID are trainable (that's why it's in trainable_list)

Applies to multiple layers: [1:-1] excludes first and last features

5F. CRD (Contrastive Representation Distillation)
==========================================
Code:
  elif opt.distill == 'crd':
      opt.s_dim = feat_s[-1].shape[1]
      opt.t_dim = feat_t[-1].shape[1]
      opt.n_data = 50000  # for CIFAR-100
      criterion_kd = CRDLoss(opt)
      module_list.append(criterion_kd.embed_s)
      module_list.append(criterion_kd.embed_t)
      trainable_list.append(criterion_kd.embed_s)
      trainable_list.append(criterion_kd.embed_t)

CRD Components:
- embed_s: Student feature embedding network
- embed_t: Teacher feature embedding network
- Memory bank: Stores feature representations

Process:
1. Embed student and teacher features
2. Use contrastive loss (NCE) to match distributions
3. Positive pairs: same sample from student and teacher
4. Negative pairs: different samples

Requires special data loader that provides contrastive indices.

5G. SemCKD (Semantic Cross-layer KD)
==========================================
Code:
  elif opt.distill == 'semckd':
      s_n = [f.shape[1] for f in feat_s[1:-1]]
      t_n = [f.shape[1] for f in feat_t[1:-1]]
      criterion_kd = SemCKDLoss()
      self_attention = SelfA(opt.batch_size, s_n, t_n, opt.soft)
      module_list.append(self_attention)
      trainable_list.append(self_attention)

SelfA (Self-Attention):
- Learns which teacher layers are most useful for each student layer
- Cross-layer matching: student_layer_i can learn from any teacher_layer_j
- Attention weights determine importance

Process:
1. Self-attention computes similarity between all layer pairs
2. Weighted MSE loss based on attention scores

Intuition:
"Student layer 2 might learn best from teacher layer 3"

5H. SRRL (Student Representation Refinement Learning)
==========================================
Code:
  elif opt.distill == 'srrl':
      s_n = feat_s[-1].shape[1]
      t_n = feat_t[-1].shape[1]
      model_fmsr = SRRL(s_n=s_n, t_n=t_n)
      criterion_kd = nn.MSELoss()
      module_list.append(model_fmsr)
      trainable_list.append(model_fmsr)

SRRL Module:
- Transforms student features to match teacher space
- Then predicts teacher logits from transformed features

Two losses:
1. MSE(transformed_student_feat, teacher_feat)
2. MSE(predicted_logits, teacher_logits)

5I. PKT (Probabilistic Knowledge Transfer) - MAIN METHOD FROM PAPER
==========================================
Code:
  elif opt.distill == 'pkt':
      from distiller_zoo import PKT
      criterion_kd = PKT()

NO ADDITIONAL MODULES NEEDED!

This is the beauty of PKT - it works directly on features of any dimension.

PKT Process (as explained in the paper):
1. Extract final pooled features: feat_s[-1], feat_t[-1]
2. Normalize to unit vectors
3. Compute cosine similarity matrices (pairwise similarities)
4. Convert similarities to probability distributions
5. Minimize KL divergence between distributions

Why no projection needed?
- Both similarity matrices are [B, B] regardless of feature dimension
- Student features: [B, 256] → similarity: [B, B]
- Teacher features: [B, 512] → similarity: [B, B]
- Dimensions match automatically!

See PKT_explained.txt for detailed algorithm.

5J. SimKD (Simple Knowledge Distillation)
==========================================
Code:
  elif opt.distill == 'simkd':
      s_n = feat_s[-2].shape[1]
      t_n = feat_t[-2].shape[1]
      model_simkd = SimKD(s_n=s_n, t_n=t_n, factor=opt.factor)
      criterion_kd = nn.MSELoss()
      module_list.append(model_simkd)
      trainable_list.append(model_simkd)

SimKD Innovation:
- Aligns features from penultimate layer ([-2])
- Reuses teacher's final classifier for student predictions
- Very simple but effective

Process:
1. Transform student features to teacher dimension
2. Match transformed features with MSE
3. Use teacher's classifier for student (no separate classifier trained)

Advantage:
- Student inherits teacher's well-calibrated classifier
- Fewer parameters to train

---
SECTION 6: CRITERION LIST
---

Code:
  criterion_list = nn.ModuleList([])
  criterion_list.append(criterion_cls)     # CrossEntropyLoss
  criterion_list.append(criterion_div)     # DistillKL
  criterion_list.append(criterion_kd)      # Method-specific

THREE LOSS COMPONENTS:
[0] criterion_cls: Classification loss (student logits vs ground truth)
[1] criterion_div: KL divergence (student logits vs teacher logits)
[2] criterion_kd: Distillation loss (method-specific)

Final loss:
  loss = cls_weight * loss[0] + div_weight * loss[1] + beta * loss[2]

---
SECTION 7: OPTIMIZER
---

Code:
  optimizer = optim.SGD(trainable_list.parameters(),
                        lr=opt.learning_rate,
                        momentum=opt.momentum,
                        weight_decay=opt.weight_decay)

KEY POINT:
Only trainable_list.parameters() are optimized!
- Student: YES
- Projection modules: YES
- Teacher: NO (not in trainable_list)

This prevents catastrophic forgetting of teacher knowledge.

---
SECTION 8: MOVE TO GPU
---

Code:
  if opt.multiprocessing_distributed:
      torch.cuda.set_device(opt.gpu)
      module_list.cuda(opt.gpu)
      distributed_modules = []
      for module in module_list:
          DDP = torch.nn.parallel.DistributedDataParallel
          distributed_modules.append(DDP(module, device_ids=[opt.gpu]))
      module_list = distributed_modules
      criterion_list.cuda(opt.gpu)

All modules wrapped in DistributedDataParallel:
- Student
- Projection modules
- Teacher (even though not trained)

Why wrap teacher?
- Still needs to do forward pass
- DDP handles device placement automatically

SECTION 11: TRAINING LOOP
---

Code:
  for epoch in range(1, opt.epochs + 1):
      adjust_learning_rate(epoch, opt, optimizer)
      train_acc, train_acc_top5, train_loss = train(
          epoch, train_loader, module_list, criterion_list, optimizer, opt)
      test_acc, test_acc_top5, test_loss = validate_distill(
          val_loader, module_list, criterion_cls, opt)
      if test_acc > best_acc:
          save_checkpoint(...)

TRAINING FLOW (for each epoch):

1. Adjust Learning Rate
   Same schedule as teacher: decay at 150, 180, 210

2. Train with Distillation (train_distill in helper/loops.py)
   For each batch:
     a. Student forward: feat_s, logit_s = model_s(images, is_feat=True)
     b. Teacher forward (no_grad): feat_t, logit_t = model_t(images, is_feat=True)
     c. Calculate three losses:
        - Classification: CrossEntropy(logit_s, labels)
        - KL Divergence: KL(logit_s, logit_t)
        - Distillation: method-specific (e.g., PKT)
     d. Combined loss: weighted sum
     e. Backward + optimizer step (updates only student + projections)

3. Validate
   Special handling for SimKD (uses projection module)
   Otherwise, standard validation

4. Save Best Model
   If current accuracy > best accuracy:
   - Save student state_dict
   - For SimKD: also save projection module
   - Save metrics to JSON

================================================================================
KEY INSIGHTS
================================================================================

1. WHY THREE LOSS COMPONENTS?
   - classification (cls): Prevents student from only mimicking teacher
   - KL divergence (div): Classic KD, matches probability distributions
   - distillation (beta): Method-specific, captures additional knowledge

   Ablation shows all three together work best.

2. WHY FREEZE TEACHER?
   - Teacher already trained to convergence
   - Provides stable target for student
   - If teacher updated, "moving target" problem

3. WHY DIFFERENT WEIGHTS FOR DIFFERENT METHODS?
   - Methods have different loss scales
   - PKT: beta=1.0 works well
   - FitNet: beta=100-1000 (MSE on features needs higher weight)
   - Attention: beta=1000 (attention maps have small values)

   These are empirically determined optimal values.

4. WHY PKT IS SPECIAL?
   - No projection modules needed (dimension-agnostic)
   - Single hyperparameter (beta=1.0 works universally)
   - Strong theoretical foundation (preserves mutual information)
   - Works across modalities (vision, text, handcrafted features)

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "Teacher accuracy is low"
CHECK:
- Correct teacher checkpoint path?
- Teacher trained on same dataset?
- Checkpoint corrupted?

ISSUE: "Student not improving"
CHECK:
- Learning rate (should match teacher's initial LR)
- Loss weights (cls, div, beta)
- Batch size (PKT works better with larger batches)

ISSUE: "Out of memory"
SOLUTIONS:
- Reduce batch size
- Use gradient accumulation
- Choose simpler distillation method (KD instead of VID)

ISSUE: "Loss becomes NaN"
CAUSES:
- Beta too high (especially for FitNet, Attention)
- Learning rate too high
- Gradient explosion in projection modules

SOLUTIONS:
- Lower beta
